КАК ПОЛУЧИТЬ ГОТОВЫЙ JAR MINUTE EVENTS 2.0

1. Создай аккаунт на https://github.com/ (если его ещё нет).
2. Нажми New repository, задай любое имя, например minute-events-2.
   Можно выбрать Public или Private.
3. Открой созданный репозиторий и выбери Add file -> Upload files.
4. Распакуй этот ZIP на компьютере и загрузи ВСЁ содержимое папки minute-events
   в корень репозитория. Важно: загрузи также скрытую папку .github.
   В ней находится .github/workflows/build.yml.
5. Нажми Commit changes.
6. Открой вкладку Actions. GitHub автоматически запустит сборку.
   Если нет запуска, открой "Build Minute Events 2.0" -> "Run workflow".
7. Дождись зелёной галочки у запуска. Открой его, найди раздел Artifacts
   и скачай Minute-Events-2.0.0-Fabric-1.21.1.
8. Распакуй скачанный ZIP. Внутри будет JAR. Положи его в папку mods.

Нужно:
- Minecraft 1.21.1
- Fabric Loader
- Fabric API
- Java 21 для игры

Если сборка красная:
Открой упавший запуск Actions, нажми шаг "Build mod" и скопируй последние
примерно 40-80 строк ошибки. Их можно прислать сюда — помогу исправить.

Важно:
- Не загружай в репозиторий пароли, токены или личные файлы.
- Не клади исходный проект внутрь дополнительной папки: build.gradle,
  gradlew, settings.gradle и .github должны быть в корне репозитория.
- GitHub Actions собирает JAR на серверах GitHub; этот архив сам по себе
  ещё не является скомпилированным модом.
