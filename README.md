# Minute Events 3.2.3 — CHAOS EDITION

Fabric-мод для Minecraft Java Edition **1.21.1**. Добавляет большую библиотеку случайных событий: катастрофы, взрывы, ловушки, нападения мобов, эффекты, подарки и события, зависящие от биома и измерения.

## Что нового в 3.2.3

- События чанков теперь воздействуют на всю поверхность выбранного чанка 16×16, а не на небольшой участок вокруг случайной точки.
- События затопления заполняют водой всю доступную поверхность чанка.
- События разрушения проходят по всем 256 колонкам чанка на заданную глубину без прежнего малого лимита блоков.

## Что нового в 3.2.2

- При открытии мира по сети хост выбирает общий режим: одно событие для всех или отдельное событие каждому игроку.
- В общем режиме все игроки получают один и тот же тип события; эффекты применяются к каждому игроку отдельно в его текущем мире.
- В общем режиме используется общий набор событий без Nether-/End-специфичных вариантов; если у кого-то накопилась серия из трёх плохих событий, группе гарантируется хорошее.
- При выборе личного режима сохраняется прежняя персональная система событий, шансов и защиты от серии неудач.

## Что нового в 3.2.1

- Исправлено отображение режимов HUD: предпросмотр показывает выбранное следующее событие, а режим процентов — вероятности подготовленных событий.
- Убраны счётчики изменённых блоков из сообщений разрушительных событий; сила самих событий сохранена.
- Синхронизированы версия мода и имя артефакта GitHub Actions.

## Что нового в 3.2.0

- Удалены события с возведением стен: вместо них используются взрывы, магмовые и огненные ловушки, паутина и взрывные засады.
- Исправлено размещение ловушек: они ставятся на подходящую поверхность, а не пытаются появиться внутри блока земли.
- TNT-ловушки используют активированный динамит с обычным игровым таймером, а не декоративный неподожжённый блок TNT.
- Обновлены сведения о версии и инструкция по установке.

## Возможности

- В одиночной игре и личном LAN-режиме события запускаются отдельно для каждого игрока с общим интервалом (по умолчанию 60 секунд).
- Есть события для обычного мира, Незера и Энда; подбор учитывает биом.
- Масштабные события получают повышенный вес при выборе.
- После трёх плохих событий подряд игроку гарантируется хорошее событие.
- HUD показывает обратный отсчёт и сведения о следующем событии.
- Доступны режим предпросмотра, режим шансов и слепой режим.
- Настройки категорий, интервала и включения событий управляются командами и сохраняются в конфигурации.

## Установка

1. Установите Fabric Loader для Minecraft **1.21.1** и Fabric API.
2. Скачайте JAR из раздела Artifacts успешной сборки GitHub Actions либо соберите проект самостоятельно.
3. Поместите JAR в папку `mods`.
4. Перед запуском на основном мире сделайте резервную копию: некоторые события разрушают блоки, создают взрывы и призывают опасных мобов.

## Команды

Все изменяющие настройки команды требуют права оператора уровня 2 или выше.

| Команда | Назначение |
|---|---|
| `/minuteevent` или `/minuteevent status` | Показать состояние и время до события |
| `/minuteevent help` | Показать справку |
| `/minuteevent on` / `off` | Включить / выключить события |
| `/minuteevent now` | Запустить событие немедленно |
| `/minuteevent interval <секунды>` | Установить интервал от 10 до 3600 секунд |
| `/minuteevent category <blocks\|cages\|traps\|walls\|mobs> on\|off` | Включить / выключить категорию |
| `/minuteevent chance <категория> <0–100>` | Настроить шанс категории |
| `/minuteevent chances` | Показать шансы событий |
| `/minuteevent mode preview` | Показывать следующее событие |
| `/minuteevent mode chance` | Показывать шансы |
| `/minuteevent mode blind` | Скрыть сведения о событии |
| `/minuteevent timer on\|off` | Показать / скрыть таймер HUD |

Настройки хранятся в `config/minute-events.properties`.

## Сборка из исходников

Требуется **JDK 21**.

Windows:
```bat
gradlew.bat build
```

Linux/macOS:
```sh
./gradlew build
```

Готовые JAR-файлы появятся в `build/libs/`.
