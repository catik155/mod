# Minute Events 2.0.0 — CHAOS EDITION

Fabric-мод для Minecraft Java Edition **1.21.1** (Java 21+).

В этой версии зарегистрировано **203 случайных события**: опасные катастрофы и ловушки, волны мобов, эффекты, полезные подарки и необычные ситуации. События запускаются отдельно для каждого игрока с настраиваемым интервалом (по умолчанию 60 секунд).

## Дополнительные катастрофы

Добавлены 100 вариантов: разрушительные ударные волны, волны враждебных мобов, ловушки, стены и отрицательные эффекты. Некоторые события изменяют мир; перед тестированием сделайте резервную копию.

## Установка готового JAR

После успешной сборки возьмите `minute-events-2.0.0.jar` из `build/libs/` и поместите его в папку `mods`. Нужны Fabric Loader для Minecraft 1.21.1 и Fabric API.

## Сборка из исходников

Нужен **JDK 21**. На Windows откройте папку проекта в терминале и выполните:

```bat
gradlew.bat build
```

На Linux/macOS:

```sh
./gradlew build
```

Готовые JAR-файлы появятся в `build/libs/`. Если Gradle Wrapper ещё не скачан, для первой сборки понадобится подключение к интернету, чтобы загрузить Gradle и зависимости Loom/Minecraft/Fabric.

## Команды

- `/minuteevent` или `/minuteevent status` — состояние и оставшееся время.
- `/minuteevent on` и `/minuteevent off` — включить/выключить события.
- `/minuteevent interval <секунды>` — интервал от 10 до 3600 секунд.
- `/minuteevent category <категория> on|off` — включить/выключить категорию (`blocks`, `cages`, `walls`, `mobs`).
- `/minuteevent chance <категория> <процент>` — вероятность категории от 0 до 100%.
- `/minuteevent now` — немедленно запустить случайное событие.

Изменение настроек доступно операторам уровня 2+. Настройки сохраняются в `config/minute-events.properties`.

## Внимание

Это CHAOS EDITION: некоторые события могут разрушать блоки, создавать взрывы, призывать опасных мобов и убивать игрока. Перед использованием сделайте резервную копию мира. Не включайте мод на важном мире без тестирования.
